# PixelPlay Universe

A responsive, expandable static browser-gaming website created by Sayeef Adnan.

## Included
- Responsive gaming portal homepage
- Search and category filters
- Favorites saved with localStorage
- Six playable games: Tic-Tac-Toe, Rock Paper Scissors, Memory Match, Neon Snake, Number Quest, Brain Blitz Quiz
- Personal best scores and rounds played saved in the current browser
- Mobile navigation, creator credits, SEO metadata
- Clearly marked advertisement placeholder (not a live ad unit)

## Run locally
Open `index.html` in a modern browser, or use a local static server.

## Publish on GitHub Pages
1. Create a GitHub repository.
2. Upload `index.html` and `README.md` to the repository root.
3. Open Settings → Pages.
4. Select deploy from the main branch and root folder.
5. Save and wait for GitHub Pages to publish.

## Customize
- Change game data and poster URLs in the `games` array in `index.html`.
- Change the contact email (`hello@example.com`) to your own contact address.
- The current stats and scores are local to each visitor's browser; there is no global online leaderboard or account system.
- The ad area is only a placeholder. Add an approved ad network's official code only after your site is accepted and in compliance with its policies.
- Some poster images are loaded from Unsplash over the internet. For an offline site, replace them with locally owned/licensed images.

## Important limitations
GitHub Pages hosts static files. Cross-device accounts, shared leaderboard, real-time multiplayer, admin uploads, and server-side data need a backend or suitable hosted service.
